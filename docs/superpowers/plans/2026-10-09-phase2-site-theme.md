## 4. 步骤

每一步一笔提交,都在分支 `feat/site-theme-v2` 上;第 2 步做完**停下给 user 看样张**。

## 7. 风险和边界

- **国内读者打开慢**:新旧样式的字体都从 Google Fonts 加载,手写字体从 jsDelivr 加载;
  国内访问 Google 不稳定时,样式表会卡住首屏渲染。[推测:依据是 Google 服务在国内常被限制;本机走代理,测不出国内直连的实际情况]
  本计划不改字体来源;如果要改,可以把字体放到本仓库自己发布,另算一步。
- **只比文字的检查有盲区**:所以第 3 步加结构基线。结构基线只数个数,表格里某一格内容错位它也查不出;
  这类靠第 2 步样张人眼看和第 7 步审查。
- **图片复制后仓库变大**:8.6 MB。git 按内容存文件,同样内容只存一份,仓库历史基本不涨;
  GitHub Pages 发布体积多 8.6 MB。
- **不做**:英文图解、公式渲染、文章内容修改、新论文图解(那是第二阶段之后的事)。
